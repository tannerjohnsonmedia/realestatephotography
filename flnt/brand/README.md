# FLNT Films — logo

A flame cut clean through by a single strike: two pieces of flint that read as fire together.

| Color | Hex |
|-------|-----|
| Ember orange | `#FF5A1F` |
| Black | `#0A0908` |

Wordmark: Archivo Black Expanded (FLNT) over Archivo Medium (FILMS), converted to outlines,
so the files never depend on installed fonts.

## Files

| File | Use it for |
|------|-----------|
| `flnt-logo-horizontal.svg` / `-2400.png` | Website header, email signature, video end cards |
| `flnt-logo-stacked.svg` / `-1600.png` | Square spaces: social profile banners, merch, watermark |
| `flnt-mark.svg` / `-1024.png` | Profile pictures (Instagram, YouTube, Vimeo), small watermark |
| `*-transparent.*` | Placing the logo over your own footage or photos |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` | Browser tab and phone home-screen icons |

Use the SVGs whenever a program accepts them (they stay sharp at any size); use the PNGs everywhere else.

## Rules of thumb

- Orange on black. On a busy image, use a transparent version where the area behind it is dark.
- Keep clear space around the logo at least the height of the "FILMS" line.
- Don't stretch, recolor, outline or add effects.
- Below about 24px tall, use the flame mark alone. The wordmark gets too small to read.
